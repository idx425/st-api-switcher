# API 快切 (ST API Switcher)

SillyTavern（酒馆）扩展：把 OpenAI 兼容接口的 **URL + API Key + 模型** 绑成站点配置，一键切换并自动重连。

酒馆内置「连接配置文件」不会给每个自定义端点单独存 Key（自定义源共用一个 Key 槽位）。换站时往往要改 URL、重贴 Key、再 Connect。本扩展把这三样做成可分组、可分页的站点列表，点一下整套切换。

- 仓库：https://github.com/idx425/st-api-switcher  
- 当前版本：**v2.3.3**

## 简介（能做什么）

- 🔌 **插头主界面**：在「API Connections / 插头」抽屉内嵌快切列表（手机端主入口）
- 🪄 **魔法棒快捷面板**：扩展菜单里点「API 快切」，弹出站点列表秒切
- 🗂️ **站点卡片**：名称 / URL / Key / 模型，可编辑、删除、导入导出
- 📁 **分组 + 折叠**：站点可归组；组头可收起；当前连接所在组有标记
- 📄 **分层分页（每页 4 条）**：未分组站点、分组列表、组内站点、表单分组芯片各自分页，布局整齐
- 🧩 **获取模型**：从目标接口拉 `/models` 列表点选（优先浏览器直连，失败再走酒馆代理）
- 🔐 **密钥只留一条**：对 `api_key_custom` 串行「先写后清」，同步 `secret_state`，减少「Secret id not found」
- 📱 **三端适配**：手机 / 平板 / 电脑；扩展设置用原生 `inline-drawer`，可收成小横条
- 🎨 **浅色主题可读**：插件自绘区强制暗底亮字，避免白字撞白底

## 安装

1. 打开酒馆 → **扩展** → **安装扩展**
2. 粘贴仓库地址：

```text
https://github.com/idx425/st-api-switcher
```

3. 安装后刷新页面；在扩展列表里确认 **API 快切** 已启用

已安装用户：扩展面板顶部点 **检查更新**，或删除后用同一链接重装（站点配置一般在本机设置里，不会因重装清空）。

## 使用

1. 扩展设置 → 展开 **API 快切** → 填写名称 / URL / Key / 模型（可选分组）→ 保存  
2. 切换入口任选其一：
   - **API Connections（插头）** 抽屉内的列表（手机推荐）
   - 站点卡片上的 **使用**
   - 魔法棒菜单 → **API 快切**
3. 切换后若未连上，到 API 页再点一次 **Connect**

## 注意事项

- 需要 SillyTavern **1.12+**
- Key 以明文存在本机扩展设置里（酒馆通用机制）；导出备份同样含明文 Key，仅建议个人设备使用
- 「当前」高亮按 URL 匹配（Key 无法安全读回比对）
- 仅作用于「聊天补全 → 自定义（OpenAI 兼容）」来源
